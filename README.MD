Real-Time E-Commerce Data Platform

Built using Apache Kafka, Spark Structured Streaming,
Delta Lake, dbt, ClickHouse, OpenSearch, Qdrant,
Airbyte, Airflow and MCP-based AI Analytics.
## Platform Operations

The platform can be monitored using K9s.

Common operations:

- Monitor Spark jobs
- Monitor Airflow pods
- View Kafka pods
- Check MinIO health
- Inspect ClickHouse deployments
- Monitor MCP services
- View logs and resource utilization
